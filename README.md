# NEPINAE 선스크린 쇼핑몰 시제품

네피내 엑토레이어 선스크린 50mL 및 휴대용 20mL를 소개하는 정적 쇼핑몰입니다.

- 50mL: 정상가 26,000원 / 판매가 20,800원
- 20mL: 정상가 11,000원 / 판매가 8,800원
- 두 상품 모두 무료배송
- 일반: 판매가 적용 / 회원: 판매가에서 추가 10% / VIP: 판매가에서 추가 20%
- 그룹 할인은 시제품 체험용 예시이며 네이버 스마트스토어의 혜택과 별개입니다.
- 실제 회원 인증, 주문, 결제는 포함하지 않습니다.

가격·이미지·상품정보는 사용자가 제공한 화면을 기준으로 반영했습니다. 첨부 화면 중 상품 이미지 영역만 SVG 뷰포트로 표시합니다. 제조일자 및 유효일자는 화면에 표시된 날짜이며 실제 입고 상품은 다를 수 있습니다.

## 실행 및 배포

Node.js에서 node server.mjs 실행 후 http://localhost:4173 에 접속합니다. GitHub Pages는 main 브랜치 루트에서 배포합니다. 상품 및 그룹 설정은 pricing.mjs에서 변경합니다.

## 모의 구매

상품 상세의 바로 구매 또는 장바구니의 주문하기에서 배송정보 → 결제수단 → 주문 확인 → 모의 결제 완료로 진행합니다. 실제 PG 연결·결제·주문 전송·배송은 없습니다. 주문 내역은 현재 브라우저에만 저장하며, 체험 정보 자동 입력을 제공합니다.
