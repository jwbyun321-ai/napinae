# MELLOW 화장품 쇼핑몰

화장품 쇼핑몰 시제품입니다. 샘플 상품 6종을 사용하며 실제 회원 인증·주문·결제는 포함하지 않습니다.

## 기능

- 상품 목록, 상세 보기, 검색, 카테고리 필터, 가격 정렬
- 장바구니 담기, 수량 변경, 삭제 및 브라우저 저장
- 일반 0%, 회원 10%, VIP 20% 할인 체험
- 그룹 변경 시 상품 가격과 장바구니 합계 자동 갱신
- 할인 후 상품금액 50,000원 이상 무료배송, 미만 3,000원
- 모바일 반응형 화면

## 실행

Node.js가 설치된 환경에서 `node server.mjs`를 실행한 뒤 http://localhost:4173 을 엽니다.

## 수정

상품과 그룹별 할인율은 `pricing.mjs`의 `products`, `groups`에서 수정합니다. 실제 서비스에서는 사용자 인증과 할인 권한을 서버에서 검증해야 합니다.

## 배포

GitHub Pages: `main` 브랜치의 `/ (root)` 폴더를 게시합니다. 별도의 빌드는 필요하지 않습니다.

모든 브랜드·상품·가격·설명은 시제품용 예시입니다.
